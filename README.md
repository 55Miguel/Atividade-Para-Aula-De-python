# FoodingGuide:
  😋Um Bot no Discord que combate contra o desperdício de alimento;
     ¬> O usuário informa os alimentos que tem em casa, e uma lista sugere receitas para aproveitar o que está perto de vencer. O app também estima a quantidade de comida que deixou de ser desperdiçada, utilizando matemática e conhecimento vindo da internet.
  
    Problema: alimentos descartados geram desperdício de recursos e emissões de gases de efeito estufa.

    Diferencial: receitas personalizadas e um placar de impacto ambiental.

    Protótipo: uma tela para inserir ingredientes e outra com receitas e estimativas de impacto.
